# 本地星图 · 投影对比工具

面向天文科普编辑的纯前端星图工具：在**球面（Three.js 天球）**、**立体投影**、**等距方位投影**三种视图下对比同一天区。无后端，所有数据保存在浏览器 IndexedDB。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 生产构建
npm test         # 坐标正确性单元测试
```

## 技术栈与职责划分

| 层 | 技术 | 职责 |
|---|---|---|
| 坐标状态 | React + TypeScript | 观测位置/时刻、视场、筛选、选中目标 |
| 天球 | Three.js | J2000 赤道坐标天球、经纬网格、视场小圆、点击拾取 |
| 投影 | D3 geo | `geoStereographic` / `geoAzimuthalEquidistant` 绘制同一天区 |
| 天文换算 | astronomy-engine | 仅用其明确支持的 `Horizon()`：J2000 赤道 → 视地平（含折射） |
| 持久化 | IndexedDB（idb） | 视场存档、目标批注 |

## 关键正确性设计

- **跨零赤经不横贯全图**：投影始终 `.rotate()` 到视场中心，RA 0h 反子午线切口被移到区域背面；`clipAngle` 限制在视场角半径附近；赤经差一律用 `signedDeltaDeg` 取最短路径。样例「飞马座大四边形」的 Scheat(23h03m)→Alpheratz(0h08m) 边跨越 RA 0h，在图中是约 16° 的短边（有单元测试守护）。
- **角距离按球面计算**：`angDistDeg` 用 atan2 稳定形式在大圆上计算；界面与导出中的角距均来自该函数。每个投影视图下方明确标注"图上像素距离不代表角距"，等距方位投影额外说明"仅离中心方向的距离真实"。
- **星等筛选与地平线裁切独立**：两个开关互不影响，可单独或组合使用；天球视图中被滤掉的星仅调暗，便于理解筛选范围。
- **观测位置与时刻可选**：纬度/经度/海拔 + UTC 时刻（输入框按 UTC 解释，可一键"设为现在"）；高度/方位角由 astronomy-engine 实时重算。
- **点击联动定位**：在天球或任一投影图中点击恒星，三个视图同时高亮同一目标；信息面板显示该目标与视场中心、与上一选中目标的球面角距。
- **导出注明坐标系与时间基准**：JSON 导出含 `meta.coordinateSystems`（J2000 赤道 / 视地平+折射）与 `meta.timeStandard`（UTC），以及观测者、视场、筛选条件、星表（RA/Dec 与视高度/方位）和批注。

## 样例星表（`src/lib/catalog.ts`）

- **极区**：勾陈一（北极星）、小熊座北斗段、南极星 σ Octantis、蛇尾一 β Hyi
- **跨零赤经**：飞马座大四边形（壁宿二、壁宿一、室宿一、室宿二，RA 23.06h–0.22h）
- **地平线附近**：老人星、水委一、北落师门、天狼星及大犬座亮星（默认观测地上海附近，老人星最高仅约 6°）
- **参考亮星**：猎户、织女、大角等约 20 颗，充实天球显示

预设按钮：北天极区 / 南天极区 / 跨零赤经（飞马方框）/ 地平线附近（按当前时刻自动选取高度 0–18° 内最接近 8° 的样例目标）。

## 已知边界

- 星表为教学用样例（约 40 颗，J2000 坐标取约值），非完整星表。
- 未绘制地平线轮廓线：astronomy-engine 不提供地平坐标→赤道坐标的逆转换，为遵守"只用明确支持的转换"，地平线裁切按恒星逐颗判定。
- 未做自行/岁差长期演化（astronomy-engine 的 `Horizon()` 内部已处理 J2000→当日的转换）。
